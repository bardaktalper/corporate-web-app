## 🛠️ Tech Stack & Features
- **Frontend:** React.js, Modern JavaScript (ES6+)
- **Styling:** SCSS / SASS (Modular architecture & responsive breakpoints)
- **Deployment:** Vercel / Cloud Infrastructure
- **Key Features:**
  - 📱 Fully responsive layout (Mobile, Tablet, Desktop)
  - ⚡ Optimized asset loading & fast page performance
  - 🎨 Clean, modern corporate UI/UX

## 💻 Local Setup & Installation

```bash
# 1. Clone the repository
git clone https://github.com/bardaktalper/corporate-web-app.git

# 2. Navigate to project directory
cd corporate-web-app

# 3. Install dependencies
npm install

# 4. Start local development server
npm start # or npm run dev
